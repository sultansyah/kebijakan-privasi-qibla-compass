Kebijakan Privasi ini menjelaskan bagaimana aplikasi Qibla Compass mengakses, menggunakan, dan melindungi informasi pengguna.

Informasi yang Diakses

Qibla Compass dapat menggunakan akses lokasi perangkat untuk menentukan arah kiblat secara lebih akurat.

Qibla Compass juga dapat menggunakan data sensor perangkat, seperti kompas atau orientasi perangkat, untuk menampilkan arah kiblat.

Kami tidak menyimpan, merekam, menjual, atau membagikan informasi lokasi pengguna kepada pihak ketiga mana pun.

Penggunaan Data

Data lokasi dan sensor hanya digunakan untuk menjalankan fungsi utama aplikasi, yaitu membantu pengguna menentukan arah kiblat.

Data tersebut diproses secara lokal di perangkat pengguna dan tidak dikirimkan ke server kami.

Penyimpanan Data

Qibla Compass tidak mengharuskan pengguna membuat akun.

Qibla Compass tidak menyimpan data lokasi atau data pribadi pengguna di server kami.

Izin Aplikasi

Pengguna dapat memberikan atau mencabut izin lokasi kapan saja melalui pengaturan perangkat.

Jika izin lokasi dicabut, beberapa fitur aplikasi mungkin tidak dapat berfungsi secara optimal.

Keamanan

Kami menghargai privasi pengguna. Karena aplikasi ini tidak menyimpan data pribadi pengguna di server kami, risiko penyimpanan data di luar perangkat dapat diminimalkan.

Privasi Anak

Qibla Compass tidak ditujukan untuk secara sengaja mengumpulkan informasi pribadi dari anak-anak.

Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan ditampilkan di halaman ini.
